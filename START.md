# Как сделать бота с игрой — три пути

Python нужен только для одного: держать сервер, который раздаёт игру, хранит сохранения
и отвечает Telegram. Сервер можно заменить — или не иметь вовсе.

| | Что нужно | Время | Регистрация и облако |
|---|---|---|---|
| **А. Совсем без сервера** | только браузер | ~5 минут | нет: прогресс живёт в устройстве |
| **Б. Без Python** (Cloudflare, JavaScript) | только браузер | ~15 минут | да: аккаунты и облачные сохранения |
| **В. На Python** (этот компьютер) | Python 3.10+ | ~10 минут | да: аккаунты и облачные сохранения |

Ничего покупать не нужно ни в одном варианте.

---

# Путь А. Совсем без сервера и без кода

Подходит, если играете сами на одном устройстве: прогресс сохраняется в самом Telegram
и переживает закрытие игры (но не переезд на другой телефон и не очистку данных).

### 1. Выложить игру бесплатно (3 минуты)

1. [github.com](https://github.com) → бесплатный аккаунт.
2. **New repository** → имя `soulclicker` → **Public** → Create.
3. **uploading an existing file** → перетащите содержимое папки `soulclicker`
   (папку `bot/` можно не загружать).
4. **Commit changes**.
5. **Settings → Pages → Deploy from a branch → main / (root) → Save**.
6. Через минуту откройте `https://ВАШ_ЛОГИН.github.io/soulclicker/` — игра работает.

### 2. Привязать к боту (2 минуты)

1. [@BotFather](https://t.me/BotFather) → `/newbot` → имя → username (`…bot`).
2. Отправьте `/newapp` → выберите бота → короткое имя, например `game` →
   заголовок → описание → **фото 640×360** (можно любое) → **URL игры**
   `https://ВАШ_ЛОГИН.github.io/soulclicker/`.
3. BotFather даст ссылку `t.me/ВАШ_БОТ/game` — это и есть вход в игру.
   Можно отправить её себе и закрепить.

Дополнительно: `/setmenubutton` → выбрать бота → указать тот же URL — тогда игра
открывается кнопкой в чате.

Готово: игра внутри Telegram, ничего не запущено и не установлено.

> Хотите ещё и кнопку «/start» в боте — без сервера не выйдет: на команды должен
> кто-то отвечать. Тогда смотрите путь Б или В.

# Путь Б. Без Python: сервер на Cloudflare (JavaScript)

Всё делается в браузере на сайте Cloudflare, ставить нечего. Появляются аккаунты,
код доступа и облачные сохранения — как в пути В.

Подробная инструкция с картинками шагов: **[`cloudflare/README.md`](cloudflare/README.md)**.

Коротко:

1. **Игра на GitHub Pages** — как в пути А, шаг 1.
2. **Worker:** [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages →
   Create Worker → вставить [`cloudflare/worker.js`](cloudflare/worker.js) → Deploy.
3. **Settings → Variables:** `BOT_TOKEN`, `WEBAPP_URL` (адрес игры),
   `SETUP_SECRET` (любая случайная строка) → Deploy.
4. **Settings → Bindings:** KV namespace с именем **`SAVES`**.
5. **Вебхук** — открыть в браузере:
   `https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<воркер>.workers.dev/tg/<SETUP_SECRET>`
6. **В игре:** в `js/config.js` вписать адрес воркера в `window.API_BASE`
   и перезалить файл на GitHub.
7. `/start` у бота → кнопка «⚔️ Открыть игру».

Проверено: сервер проходит 19 автотестов (`node tools/test-worker.mjs`) и работает
с игрой, включая кросс-доменные запросы.

# Путь В. На Python (полный контроль)

Сервер и бот в одном файле, без сторонних библиотек. Подходит, если хотите держать
всё у себя или на своём сервере.

### 1. Запустить

```bash
cd soulclicker/bot
python bot.py
```

Откройте <http://127.0.0.1:8080/> — игра работает, профиль создаётся сам.

### 2. Бесплатный HTTPS

Telegram открывает Mini App только по HTTPS:

```powershell
winget install --id Cloudflare.cloudflared     # Windows
cloudflared tunnel --url http://127.0.0.1:8080
```

Скопируйте выданный адрес `https://…trycloudflare.com`.

### 3. Подключить бота

В `bot/.env`:

```env
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxx
WEBAPP_URL=https://random-words-here.trycloudflare.com
```

Перезапустить `python bot.py` → в логах `Mini App включён` → `/start` у бота.

### 4. Чтобы работало круглосуточно

Туннель живёт, пока открыт компьютер. Варианты «всегда онлайн»:

- **свой ПК включённым** — бесплатно, ноль настроек;
- **Oracle Cloud Always Free** — бесплатная VM, нужна карта для проверки;
- **любой VPS** за 100–200 ₽/мес + домен.

Готовый systemd-юнит и Docker — в [`bot/README.md`](bot/README.md).

# Регистрация и сохранения (пути Б и В)

| Где играете | Как входите | Где прогресс |
|---|---|---|
| **Telegram** | автоматически, по аккаунту Telegram: сервер проверяет подпись `initData` токеном бота, подделать нельзя | облако + локально |
| **Браузер** | профиль создаётся сам, выдаётся код `ABCD-EFGH` | облако + локально |

- Прогресс уходит в облако автоматически и в момент закрытия игры.
- При возвращении берётся более свежее сохранение (облако или локальное).
- **Перенос на другое устройство:** «ПРОФИЛЬ» → ввести код → прогресс подтянется.
- «СБРОС» удаляет прогресс и локально, и в облаке.
- Без сервера игра продолжает работать и копит прогресс локально.

# Если что-то не так

| Симптом | Причина и решение |
|---|---|
| Игра не открывается по `github.io` | Pages не включён или прошло меньше минуты; проверьте вкладку Actions |
| В Telegram «Не удалось открыть» | ссылка не https, или в BotFather указан адрес с опечаткой |
| Бот не отвечает на `/start` | так и должно быть в пути А — там нет сервера; используйте ссылку `t.me/бот/app` |
| «ОБЛАКО: НЕТ СВЯЗИ» | не указан `API_BASE` (путь Б) или сервер выключен (путь В) |
| Код доступа не подходит | 8 символов, вводятся в «ПРОФИЛЬ» без пробелов |
| Порт 8080 занят | `PORT=8090 python bot.py` (и туннель на этот порт) |
